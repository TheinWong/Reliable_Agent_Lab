# Starter Pack Manifest

This pack is documentation-first. It is intended to be unzipped and handed to Codex so Codex can implement the project using Goal mode.

Key entrypoints:
1. `AGENTS.md` — compact persistent repository rules/map.
2. `CODEX_GOAL.md` — v0.1 release completion contract.
3. `docs/INDEX.md` — modular context map.
4. `.agent/PLANS.md` — ExecPlan protocol.
5. `.agent/exec-plans/active/0001-foundation-and-first-vertical-slice.md` — initial plan.
6. `docs/40-codex/*` — high-autonomy Codex operating rules.

The pack intentionally does not include finished application code. Codex should create it incrementally while preserving the documentation and updating plans/status as evidence changes.
