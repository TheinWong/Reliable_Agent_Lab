# Learning Notes

This directory contains maintainer-written notes for concepts learned while building Reliable Agent Lab.

These are not generated API docs. They are intended to become interview-ready explanations backed by the actual project.

Recommended format for each note:

```text
# Concept

## Problem

## Mental model

## How this project uses it

## Alternatives and trade-offs

## Failure cases

## What I implemented personally

## Interview questions I should be able to answer
```

Codex may review, correct, and improve these notes, but the human maintainer should preferably write the first explanation for core concepts.
