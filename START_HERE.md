# START HERE — For Codex

This repository scaffold is designed for high-autonomy implementation with Codex Goal mode.

## First pass
1. Read `AGENTS.md`.
2. Read `CODEX_GOAL.md`.
3. Read `docs/INDEX.md`.
4. Read `.agent/PLANS.md` and the current active ExecPlan.
5. Read only the architecture/engineering docs referenced by that ExecPlan.

Do not load every document into context unless needed.

## Then
- activate/confirm a Codex Goal based on `CODEX_GOAL.md`;
- inspect the local environment/toolchain;
- update the active ExecPlan with concrete commands/constraints discovered;
- create a non-main working branch if this is a Git repository;
- begin implementing the first vertical slice;
- keep working across milestones until the Goal is evidence-complete or a real blocker is reached.

## Priority
Working, tested vertical slices > broad scaffolding.
Actual evidence > README claims.
Autonomous implementation > frequent user questions.
Explicit blockers > silent shortcuts.
