# Contributing

Thank you for contributing to Reliable Agent Lab.

## Before coding
- read `AGENTS.md` and `docs/INDEX.md`;
- open/use an Issue or ExecPlan for non-trivial changes;
- keep scope aligned with the roadmap.

## Branches
Do not work directly on `main`.
See `docs/60-github/GITHUB_WORKFLOW.md`.

## Quality
Run relevant Python/Java tests and lint/type/build checks.
Add tests for behavioral changes.
Update architecture/docs when public behavior or boundaries change.

## Pull requests
Explain why the change exists, what changed, how it was tested, and known limitations.
Do not submit secrets or machine-specific local configuration.
